BillboardApp

WPF digital signage app for rotating PC monitor content display

Type: Visual Studio (C#/WPF)
Date: 2024-09-15
1 of 4

Overview

Billboard App is a comprehensive Windows desktop application that transforms a PC monitor (or multiple monitors) into a rotating content display with multi-monitor support, content scheduling, music/audio, and a full admin panel.

Features

  • Multi-monitor support with Mirror, Sequential, and Conveyor display modes
  • Image and video content rotation with configurable intervals
  • Animated text slides with full styling options
  • Scrolling banner ticker with directional control
  • Background music loop with per-slide audio support
  • Audio device selector for flexible output routing
  • System tray integration for quick access to admin panel

Tech Stack

C# WPF Windows Desktop
